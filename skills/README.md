# Skills Plan

이 폴더는 워크북에서 반복되는 절차를 Codex skill로 전환하기 위한 설계 메모를 보관한다.

초기 후보:

- requirement-to-harness
- data-quality-audit
- metric-discovery
- dashboard-automation-spec
- agent-audit

각 skill은 다음 구조를 갖는다.

```text
SKILL.md
templates/
examples/
checklists/
```

전환 기준:

- 같은 절차가 세 번 이상 반복된다.
- 입력과 출력 계약이 명확하다.
- 검증 기준이 체크리스트로 고정 가능하다.
- 승인 경계가 분명하다.
