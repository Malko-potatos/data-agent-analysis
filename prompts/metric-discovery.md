# Metric Discovery Prompt

```text
원천 데이터에서 만들 수 있는 metric 후보를 발굴해주세요.

목표:
- 공식 KPI를 단정하지 않고, 계산 가능한 metric 후보와 필요한 확인 사항을 분리합니다.

입력:
- 원천 데이터 파일 또는 DB table
- 컬럼 설명이 있다면 함께 사용
- 업무 목적 또는 의사결정 질문

절차:
1. 컬럼 사전을 작성하세요.
2. row grain과 key 후보를 확인하세요.
3. 계산 가능한 metric 후보를 생성하세요.
4. 각 metric의 계산식, source column, 단위, 기간 기준을 적으세요.
5. 계산 가능, 조건부 가능, 불가능으로 분류하세요.
6. 신뢰도를 높음/중간/낮음으로 표시하세요.
7. 사람에게 확인해야 하는 업무 정의를 질문으로 남기세요.

제약:
- 공식 metric처럼 단정하지 마세요.
- source에 없는 값을 추정해 채우지 마세요.

검증:
- row count와 결측률을 기록하세요.
- sample row로 계산식을 검산하세요.
- 분자, 분모, 제외 조건을 명시하세요.

출력:
- 컬럼 사전
- metric 후보 table
- 계산 가능성 분류
- 확인 필요 질문
- 다음 분석에 필요한 추가 데이터
```
