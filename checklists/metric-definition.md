# Metric Definition Checklist

## Metric Identity

- [ ] metric 이름이 있다.
- [ ] metric의 의사결정 용도가 명확하다.
- [ ] metric owner 또는 reviewer가 있다.

## Formula

- [ ] 계산식이 있다.
- [ ] 분자와 분모가 명시되어 있다.
- [ ] 단위가 명시되어 있다.
- [ ] 기간 기준이 명시되어 있다.

## Inclusion / Exclusion

- [ ] 포함 조건이 있다.
- [ ] 제외 조건이 있다.
- [ ] 환불, 취소, 테스트 데이터 처리 기준이 있다.
- [ ] 중복 사용자 또는 session 처리 기준이 있다.

## Reliability

- [ ] source column이 확인되었다.
- [ ] source total과 대조했다.
- [ ] sample row 검산을 했다.
- [ ] 신뢰도를 높음/중간/낮음으로 표시했다.

## Unknowns

- [ ] 확인 필요 사항을 숨기지 않았다.
- [ ] 계산 불가능한 metric은 불가능하다고 표시했다.
- [ ] 조건부 가능 metric은 필요한 추가 데이터를 적었다.
